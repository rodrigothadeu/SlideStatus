# Contribuindo para o SlideStatus

Obrigado pelo seu interesse em contribuir para o SlideStatus! Este projeto visa facilitar a gestão de workflow em apresentações do Google Slides, e toda ajuda é bem-vinda.

## Como começar?

1.  **Reportando Bugs**: Se encontrar um erro, abra uma *Issue* descrevendo o problema, o comportamento esperado e passos para reproduzir.
2.  **Sugerindo Melhorias**: Ideias para novas funcionalidades ou ajustes visuais são muito bem-vindas via *Issues*.
3.  **Enviando Pull Requests**:
    *   Faça um Fork do repositório.
    *   Crie uma branch para sua alteração (`git checkout -b feat/minha-melhoria`).
    *   Faça suas alterações.
    *   Envie um Pull Request detalhando o que foi feito.

## Padrões de Desenvolvimento

- **Commits**: Utilizamos o padrão [Conventional Commits](https://www.conventionalcommits.org/).
- **Código**: Como o projeto utiliza Google Apps Script, tente manter o código simples e evite dependências externas pesadas no frontend para garantir performance.
- **Idioma**: O código e comentários devem preferencialmente seguir o que já está estabelecido, mas o suporte ao usuário e documentação principal são em Português.

## Processo de Pull Request

1. Garanta que seu código não quebra funcionalidades existentes.
2. Atualize o `README.md` se sua alteração adicionar ou mudar funcionalidades.
3. A versão do projeto será atualizada pelos mantenedores durante o release.
